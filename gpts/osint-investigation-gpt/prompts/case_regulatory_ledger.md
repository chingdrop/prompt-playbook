# Prompt Card — Litigation & Regulatory Ledger

Create a ledger of **material** litigation/regulatory items relevant to organizational risk.

## Output fields (repeat per item)

- Item ID:
- Jurisdiction:
- Parties (organizational entities only):
- Docket / case number / regulator reference:
- Event dates (filed / hearings / order / disposition), if known:
- Procedural posture / status:
- What is verified vs alleged:
- Evidence log item IDs:
- Notes / limitations:

## Rules
- A complaint is an allegation until confirmed by filings, judgments, or regulator decisions.
- Keep entries time-aligned to the scope timeframe; older items must be clearly labeled.
