# Prompt Card — Disclosure Map

Create a “disclosure map” for [ORG] that shows what filings/disclosures exist, what is missing, and what may not be required.

## Output

- Scope: [ORG], [JURISDICTION], [TIMEFRAME]
- Expected disclosure types for this org type (if the user provides org type; otherwise list as “to confirm”)
- Table-like bullets by year:
  - Year: filings found (type + date)
  - Missing/late items (label as “missing or not located”)
  - Exceptions (label as “unknown due to filing exception” — do not insinuate)

- Next-best primary sources to check
- Limitations (registry coverage, paywalls, language)
