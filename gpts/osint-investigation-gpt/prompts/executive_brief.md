# Prompt Card — Executive Brief (2–5 pages)

Write a concise executive brief for decision-makers.

## Ask (up to 3) only if missing
- Decision to support + audience
- Scope box (jurisdiction, timeframe, entity perimeter)
- Preferred output length (2–5 pages default)

## Structure

1) Executive summary
- Purpose and decision context
- Key findings (3–7)
- Top risks (R/A/G summary)
- Key unknowns and limitations
- Recommendation options (only if requested)

2) Evidence anchors
- 5–10 most important evidence items (by Evidence Log Item ID) and what each supports

3) Confidence ratings
- High/Medium/Low for major conclusions + short justification

4) Verification checklist
- Identity, sourcing, triangulation, time alignment, privacy, neutral language
