# Prompt Card — Allegation Register (Neutral + Non-identifying)

Create an allegation register that minimizes harm and avoids laundering misinformation.

## Output fields (repeat per allegation)

- Allegation ID:
- Allegation summary (non-identifying; avoid naming private individuals):
- Source type (UGC / media / complaint / regulator / other):
- Source quality notes:
- Date first observed / timeframe relevance:
- Verification steps taken:
- Verification steps to take next:
- What is confirmed vs unconfirmed:
- Escalation required? (Y/N) + rationale:
- Notes / limitations:

## Rules
- Treat allegations as leads for verification, not conclusions.
- Prefer official records and regulator guidance for serious matters.
- Do not include personal data (home addresses, personal contacts, family details, routines).
