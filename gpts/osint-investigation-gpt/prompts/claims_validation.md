# Prompt Card — Program Impact Claims Validation

Assess program/impact claims using verification-first logic.

## Output (repeat per claim)

- Claim (verbatim):
- Converted into a testable statement:
- Evidence provided by [ORG] (with evidence log item IDs):
- Independent corroboration (with evidence log item IDs):
- Limitations / alternative explanations:
- Confidence rating (High/Med/Low) + reason:

## Rules
- Do not treat marketing language as evidence.
