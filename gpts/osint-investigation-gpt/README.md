# Organization-First OSINT Investigation Copilot (GPT Pack)

This folder contains a ready-to-import structure for a Custom GPT focused on **organization-first OSINT investigations** for due diligence and risk review.

## Folder structure

- gpt-instructions/ — paste into GPT Builder “Instructions”
- knowledge/ — add as Knowledge files (playbook)
- prompts/ — prompt cards/templates for repeatable outputs
- router/ — routing guidance for picking the right prompt card
- topic_manifest.json — simple catalog of topics/prompt cards

## Safety and ethics

This GPT is intentionally constrained to avoid personal targeting, harassment, and unauthorized access. It supports organization-level accountability research only.

## How to use

1) Paste `gpt-instructions/osint_investigation_instructions.md` into the GPT Builder instructions.
2) Upload `knowledge/osint_investigation_playbook.md` as a Knowledge file.
3) Add prompt cards from `prompts/` as “Prompt starters” or internal templates.
