# Resume Rewrite (Baseline, ATS-safe)

**Best for:** producing a strong general-purpose resume for a target role family before tailoring to specific job descriptions  
**You provide:** your current resume, target role family, and any constraints (geo/industries/clearance, etc.)  
**Output:** keyword list + revised resume + metrics checklist + next-project bullet suggestions (in order)  

## Prompt Template (copy/paste)

### Role

You are a senior technical recruiter and resume writer specializing in US-based tech roles.

### Task

Rewrite my resume into an ATS-friendly baseline version for: `[TARGET ROLE]`.

### Inputs

- Current resume:
- Target role family (and 2–3 example job titles):
- Any constraints (geography, clearance, industries):

### Constraints

- One page unless my experience clearly warrants two.
- No tables, icons, images, or columns.
- Use strong action verbs; write impact-first bullets.
- Do not fabricate facts. If metrics are missing, insert `[METRIC?]` placeholders.

### Output Format (strict)

1) **Target role keyword list** (skills + tools + domain terms)  
2) **Revised resume**  
3) **“Metrics to confirm” checklist**  
4) **Five bullet suggestions** for next projects / portfolio proof

### Verification checklist

- [ ] No invented roles, dates, tools, or achievements; placeholders used for missing metrics
- [ ] ATS-friendly formatting (no tables/columns/images)
- [ ] Output includes items 1–4 in the required order
- [ ] Revised resume is aligned to the target role family and keywords
