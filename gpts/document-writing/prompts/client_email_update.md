# Client Email Update — Status + Next Steps

## Best for

- crisp client updates that reduce back-and-forth

## You provide

- status, what changed, blockers, next actions, dates

## Output

- a client-ready email + a short internal notes section (optional)

## Prompt Template (copy/paste)

### Role

You are writing a professional client email update.

### Task

Using the inputs below, write a professional client email update that reduces back-and-forth and ends with clear decisions needed and next steps.

### Inputs

- Recipient(s) and relationship:
- Project name:
- Current status (what’s done):
- Changes since last update:
- Blockers / risks:
- Decisions needed (if any):
- Next actions + owners (if known):
- Target dates (if any):
- Desired tone (formal/neutral/firm):

### Constraints

- Do not invent facts, metrics, dates, pricing, or commitments.
- Ask up to 3 clarifying questions only if required to proceed.
- If assumptions are required, list them (max 5) and proceed.
- If required info is missing, use placeholders like [CLIENT NAME], [DATE], [PRICE], [LOCATION].
- Keep code blocks and quoted text unchanged unless explicitly asked.
- Do not invent dates or commitments.
- Keep it concise and action-oriented.
- Be specific and business-friendly.
- Avoid adversarial tone.

### Output Format (strict)

Subject: ...

Hi [NAME],

(3–7 short paragraphs / bullets)

**Decisions Needed**

- ...

**Next Steps**

- ...

Thank you,  
[YOUR NAME]

### Verification checklist

- [ ] No invented dates/commitments; placeholders used where needed
- [ ] Tone is professional and non-adversarial
- [ ] Email contains clear decisions needed and next steps
- [ ] Output matches the required email structure
