# Obsidian Notes

This repo uses **standard Markdown links** (`[text](relative/path.md)`), which Obsidian renders and follows reliably.

Optional: If you prefer Obsidian wiki-links (`[[Note Name]]`), you can enable them in Obsidian and convert links later, but standard links are recommended here because they:
- work in GitHub preview
- work in Obsidian
- remain stable across folders and filenames
