# Obsidian Notes

This repo uses **standard Markdown links** (`[text](relative/path.md)`), which Obsidian renders and follows reliably.

## Link rules

- Use Markdown links for real internal references, for example: [`docs/repo_consistency_rules.md`](repo_consistency_rules.md).
- Keep placeholder paths as inline code, for example: `gpts/<topic>/router/00_router.md`.
- Prefer relative links inside the repo; they work in GitHub preview and Obsidian.

## Optional wiki-links

If you prefer Obsidian wiki-links (`[[Note Name]]`), you can add them locally, but standard links are recommended here because they:

- work in GitHub preview
- work in Obsidian
- remain stable across folders and filenames
