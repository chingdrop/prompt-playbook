# `docs/ai/` templates

These are **copy/paste templates** intended to be placed into the target project repository (the repo you want the copilot to help with).

Recommended workflow:
1. Copy this folder into your project repo as `docs/ai/`.
2. Fill out `context.md` first.
3. Use `how_we_work.md` to define expectations (small changes, verification, no invented facts).
4. Use `decision_log.md` to record “why” behind important choices.
